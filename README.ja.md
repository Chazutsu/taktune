# Taktune

Tune your time. Taktune is an Obsidian-native workspace for tasks, time blocking, habits, and weekly reviews. Markdown checkboxes remain the source of truth, so your data stays readable without the plugin.

The interface is English by default and includes Japanese. Choose **System default**, **English**, or **Japanese** in Taktune settings. Product-specific copy lives in `src/locales`; only locale resolution and interpolation are candidates for promotion to the shared plugin kit.

以下は現行機能を説明する日本語版ドキュメントである。英語正本は[README.md](README.md)を参照。

UIは英語を既定とし、日本語にも対応する。Taktune設定で「システム既定」「English」「日本語」を選択できる。プロダクト固有の文言は`src/locales`で管理し、ロケール解決と補間だけを共有plugin kitへの昇格候補とする。

> 互換性のため、Obsidian内部のプラグインIDと既存データパスは`ticktick-dashboard`のまま維持する。

## 開発と配布

- 開発正本は`src/plugin.cjs`、`src/settings.cjs`、`src/ui/**/*.tsx`
- React 19、TypeScript、Rolldown、Tailwind 4を採用。全画面をReactコンポーネントとTailwind utilityへ移行し、手書きの旧CSSを撤去済み
- `pnpm test`でReact UIと単一ファイルbundleへ回帰テストを実行する
- `pnpm test:visual`でdesktop light/darkとmobileの主要画面を画像比較する
- `pnpm test:obsidian-shell`でデバッグポート付きの実Obsidianへ接続し、主要導線を読み取り検証する
- Vault走査またはReact描画に失敗した場合は空白画面にせず、原因と「再試行」をDashboard内へ表示する。モバイルでは再試行ボタンを44px以上にする
- `pnpm check:release`でbuild後にmanifest、最低Obsidian版、配布物ハッシュを検査する
- ルートの`main.js`、`styles.css`、`manifest.json`がGitHub Releaseおよび手動インストール用の自己完結した配布物
- GitHub Actionsの`Release Taktune`へ`manifest.json`と同じ版を入力すると、版整合・全回帰を確認してBRAT用の3成果物をReleaseへ添付する
- BRAT 1.1.0以降でこのリポジトリを追加すれば、最新Releaseからインストール・更新できる

- 新規インストールのタスク追加先は`Taktune/Inbox.md`、ゴミ箱は`Taktune/Trash.md`
- 振り返りは`Taktune/Reviews`、カレンダーキャッシュと設定バックアップは`Taktune/.data`、再利用するダッシュボードノートは`Taktune/TODO.md`へ保存する
- 既存設定に保存先項目がない場合は、従来の`private/tasks`、`private/reviews`、`private/.ticktick-dashboard`、`private/TODO.md`を維持する。すべて設定画面から変更できる
- 集計対象外のパス断片も設定できる。既定値は`/archive/`
- クイック追加: `明日 !高 ~仕事 #確認 毎週`のように、日付・優先度・リスト・タグ・繰り返しを入力欄から解析
- `明日9時30分 会議`や`今日 14:00 レビュー`の日時も解析し、期限とリマインダーへ変換する
- `10分前`・`2時間前`・`1日前`の相対通知に対応する。追加欄とクイック追加には、認識したタイトル・期限・通知・分類の保存前プレビューを表示する
- 設定画面で新規タスクの既定期限・リスト・優先度・通知時刻を指定できる。画面上の追加欄とホットキー追加へ共通適用する
- 期限記法: `📅 YYYY-MM-DD`
- 完了日記法: `✅ YYYY-MM-DD`
- 優先度: `⏫` 高、`🔼` 中、`🔽` 低
- アイゼンハワーマトリクス: 象限間のドラッグ、または編集画面から`#重要`・`#緊急`を更新
- カレンダー: Google Calendar予定を日/週タイムラインへ表示し、未配置タスクを任意の日・時刻へドラッグして時間割を作成。空き時間のクリックから時間付きタスクを直接作成でき、Obsidianタスクはリストで表示を絞り込める
- Google CalendarはVault内の同期済みキャッシュから複数カレンダーの名称・色・予定を読み取る。初期状態はprimaryのみで、会議室などを自動購読しない
- 配布bundleはNode.jsのプロセスAPIを含まず、外部コマンドを起動しない。リアルタイム更新には公開ICS URLの購読を使う
- Google予定キャッシュは最大2,000件・約6か月分を扱う。選択カレンダーと表示期間がキャッシュ済みの場合だけ表示し、更新から48時間以上なら警告する。未同期期間を空予定として誤表示しない
- Outlook、iCloud、その他の公開カレンダーは`https://`または`webcal://`のICS購読URLを複数登録できる。購読ごとの表示切替・名称・色、終日/時刻指定予定、基本的な日次・週次・月次・年次繰り返し、除外日を読み取り専用でカレンダーへ統合する
- 複数カレンダーの一部だけ取得に失敗した場合、成功した予定は表示したまま、失敗したカレンダー名と理由を時間割上部へ警告する
- タスク時間枠: `⏰ YYYY-MM-DD HH:mm-HH:mm`としてMarkdownへ保存
- 複数日の期間タスクは`⏰ 開始日 開始時刻→終了日 終了時刻`として保存する。期間中の各日にカレンダー表示し、初日・中間日・最終日の時間帯を日境界で分割する
- リスト: `📋 リスト名`。サイドバーの`+`またはタスク編集から作成・移動
- タグ: Obsidian標準の`#タグ`。サイドバーの`+`またはタスク編集から作成
- リスト・タグ名を`仕事/開発`のように区切ると、サイドバーでフォルダ階層として表示
- セクション: `🗂 セクション名`。リスト画面でグループ化し、Kanbanでは対象リストを選ぶとセクション列として作成・名称変更・削除・DnD移動できる
- リスト・タグはサイドバーから名称変更・削除でき、Vault内の該当タスクへ一括反映
- リスト・タグは色を設定でき、サイドバーでドラッグして並び順を保存できる
- サブタスク: 親タスクより2スペース深いMarkdownチェックボックス。編集画面でタイトル・複数リマインダーを変更し、ドラッグまたは上下ボタンで並べ替えできる
- 進捗: サブタスクがある親は完了数から自動算出。単独タスクは編集画面から5%刻みで設定し、`📊 65%`としてMarkdownへ保存
- 作業見積もり: Pomodoro数を`🍅 3`、所要時間を`⏳ 90m`として保存する。タスク一覧へ表示し、フォーカス画面で選択すると見積時間をタイマーへ反映する
- タスクはダッシュボードから編集・複製・ゴミ箱への移動ができる。親を移動すると配下のサブタスクも追従する
- 実行しないと決めたタスクは`🚫`として「やらない」スマートリストへ退避できる。個別・一括操作に対応し、チェックボタンから通常タスクへ戻せる
- 削除したタスクは設定したゴミ箱ノートへ子孫・メモごと移動する。新規インストールの既定値は`Taktune/Trash.md`。サイドバーの「ゴミ箱」から元ノートへ復元できる
- タスクメモ: タスク直下の`  > 📝 メモ`。複数行、Markdownリンク、`[[添付ファイル]]`を編集画面から保存・表示
- 添付ファイルは編集画面で複数選択またはドラッグでき、Obsidianの添付先設定へ保存する。画像は埋め込み、その他は内部リンクとしてメモへ追記する
- 添付済みファイルは編集画面から開ける。リンク解除はVault内のファイル本体を削除しない
- メモ編集には太字・斜体・コード・リンク・チェックリストのMarkdownツールバーを備える
- コメントは編集画面から追記でき、`  > 💬 ISO日時 コメント`としてタスク内へ保存する。変更履歴も`  > 🕘 ISO日時 操作内容`として自動記録し、直近20件を編集画面で確認できる
- コメントは複製・移動・ゴミ箱復元でタスクに追従する。複製時は元タスクの変更履歴を引き継がない
- 未完了タスクは`- 🗒️ タイトル`形式のノートへ変換できる。「ノート」画面からタスクへ戻せ、メモ・コメント・添付・サブタスク相当のチェック項目・変更履歴を同じMarkdownブロック内に保持する
- タスクテンプレート: 編集中のタスクから期限の相対日数、リスト、タグ、優先度、繰り返し、メモ、サブタスクを保存し、クイック追加から再利用。クイック追加では名前・内容・リスト・タグを横断検索でき、設定画面ではDnDまたは上下ボタンで表示順を変更できる
- 複数選択モードで、リスト移動・期限変更・優先度変更・タグ追加/解除・完了・やらない・削除を一括実行。2件以上の未完了ルートタスクは、残す親を選んで統合でき、統合元のメモ・コメント・添付・サブタスク・履歴を子タスクとして保持する
- フォーカス: 25分/50分タイマーと経過時間を測るストップウォッチ、対象タスク選択、再起動後の状態復元、直近7日チャート、30日合計・セッション数・計測方式別・タスク別の集中実績
- 習慣: 実施曜日または週N回、1日あたりの数値目標と単位、複数時刻の通知、直近7日履歴、35日ヒートマップ、過去日の修正、日/週の連続達成数、履歴を保持したアーカイブ。タスク完了履歴とは分離して保存
- カウントダウン: 誕生日・記念日・試験・締切などの重要日をカードで管理し、残日数または経過日数を表示する。当日を0日/1日目にする計算方式、メモ、色、当日または最大30日前の通知、毎月・毎年・月末・第N曜日の繰り返しに対応し、発生日はカレンダーにも表示する
- 統計: 直近7日の完了数、時間割実行、集中時間、習慣達成率、14日間の完了推移、未完了の優先度・リスト分布
- 週次振り返り: 直近7日の実績と集中記録、時間割の実行件数を確認する。時間割に置いたまま未完了のタスクと期限超過タスクは、由来を区別して持ち越し理由を判断し、外部Issue由来ならLinear/Jira/Slackの出所も画面とMarkdownへ残す。学び、次の7日間の重点1〜3件とともにMarkdownへ保存する。重点が空、4件以上、または持ち越し理由が未選択の間は保存しない。金曜以降の初回、または前回から7日後は今日画面から振り返りへ案内し、不要なら次の金曜まで閉じられる。Markdown作成後は前回指標・案内抑止解除・下書き消去を1回の設定保存へまとめ、失敗時は下書きと旧設定を保持する。同一ノートを再利用して重複なしで再試行でき、保存成功後だけ画面上の下書きを消す。前回重点は時間割へ直接送れ、同名タスクが配置済みなら既存時間枠の日を開いて未配置として重複操作しない。狭い画面では主要操作を44px以上にする
- 保存済みの振り返りは画面末尾の折りたたみ履歴から直近8件を開ける。現在の振り返り手順を圧迫せず、日付順に過去の判断と学びへ戻れる
- 前回重点を時間割へ送る処理は実行中の重複操作を止め、失敗理由を行内表示する。タスク作成後に画面遷移だけ失敗しても作成キーを保持し、再試行で同じタスクを再利用する
- 620px以下では共通アプリバー、主要ビュー、カレンダーの日付移動・検索・期間切替を40〜44pxの操作領域に拡大する。バーは増やさず横スクロールで幅不足を吸収する
- 720px以下のナビゲーションは背景タップで閉じず、明示的な閉じる操作を使う。ビュー・折りたたみ・分類追加/編集を40〜44pxへ拡大し、リスト/タグ編集をホバーなしで常時表示する
- 横長画面では今日・Inbox・一覧などの操作面を左寄せ最大1280pxに制限し、入力欄から行操作までの視線移動を抑える。時間割とKanbanは複数列を比較するため全幅を維持する
- コマンドパレットの「タスクをクイック追加」から、どのノートを開いていてもテンプレートと入力解析を使って追加
- Obsidianが前面にある時は`Shift+Alt+A`でクイック追加を開き、Enterで保存する。キー割り当てはObsidianのホットキー設定から変更可能
- 繰り返し: `🔁 every day` / `every weekday` / `every week` / `every month` / `every year`。`every 2 weeks`のような任意間隔にも対応
- 曜日・月内指定: `every monday,wednesday,friday`、`every month on day 15`、`every month on last day`、`every month on first monday`、`every month on last friday`
- 繰り返しタスクを完了すると完了履歴を残し、次回期限の未完了タスクを生成
- 繰り返しは「今回をスキップ」に対応
- リマインダー: `🔔 YYYY-MM-DD HH:mm`を複数設定可能。時間枠の終了時刻もワンクリックで追加でき、完了、元タスクを開く、5/15/60分スヌーズ、解除を通知画面から操作できる
- 最終確認時刻とスヌーズを保存し、Obsidian再起動後は最大24時間の通知漏れを回収。コマンドパレットからOS通知も有効化できる
- コマンドパレットの「動作環境を診断」は、設定schema、Inbox保存先、SecretStorage、ステータス、Google予定キャッシュの件数・鮮度、通知権限、外部連携設定を重要度別に表示し、問題ごとの対処を案内する
- リボン・コマンド・通知からタスク画面を開く時は既存Dashboardタブを再利用する。同時に複数回呼ばれても起動処理を一本化し、起動時には重複タブを閉じる
- 既定の「集中表示」はタスク画面を開いている間だけObsidianの左右サイドバーを収納し、別タブへ移動すると直前の開閉状態へ戻す。設定画面で無効化でき、Dashboard内で手動再表示してもlight dismissしない
- Markdown走査は行数に対して線形に処理し、タスク・ノート集計間でファイル読込を共有する。1万タスク規模の性能上限、読込回数、ノート内チェック項目の除外をbundle回帰で検査し、実Vaultの収集・表示時間は診断画面へ表示する
- スマートリスト: 今日、明日、次の7日間、期限切れ、予定済み、繰り返し
- 保存フィルター: キーワード・リスト・タグ・優先度・期限条件をAND結合し、サイドバーへ保存
- 表示設定: スマート・手動・期限・優先度・名前・作成日時・更新日時・元ノート順のソートと、期限・優先度・リスト・タグ・セクション・作成日時・更新日時単位のグループ化。複数タグは先頭タグを代表にする。日時順は昇順/降順を選べ、日時グループは今日・昨日・過去7日間・今月・以前へ分ける。手動順ではタスクを上下へドラッグ、またはフォーカス可能な上下ボタンで移動できる。別ノートへ移す場合もメモ・コメント・サブタスクを一塊で移動する。サブタスク階層は維持
- 新規タスクと複製タスクは作成履歴を保存する。既存タスクの作成・更新日時は変更履歴、コメント、ノートのファイル時刻から安全に補完する
- カレンダー配置済みタスクは、所要時間を保ったまま日・時刻をドラッグ変更できる。予定や別タスクと時間が重なった場合は、警告枠と「予定と重複」「別のタスクと重複」で配置競合を明示する。ドロップ先の時刻ガイド、日末での終了時刻補正、下端ドラッグによる15分単位の所要時間変更、未配置への戻しにも対応。720px以下ではタスク右上の操作メニューから15分短縮・延長・未配置化できる
- 未配置タスクは検索と優先度・期限・名前順の切り替えに対応。複数件を選び、日付・開始時刻・所要時間を指定して表示順に連続配置できる。選択中のタスク群を時間軸へドラッグしても一括配置できる
- 720px以下では未配置トレイをDnDに依存させず、複数選択・検索・日時指定・配置を40〜44pxの操作領域にする。配置中はフォームをロックし、書き込み失敗を行内表示して同じ選択のまま再試行できる
- カレンダーの複数選択から、開始時刻と所要時間を保ったまま+1日・+1週・指定日へ一括延期できる
- カレンダー表示設定から、タスク時間枠の色をリスト・先頭タグ・優先度基準で切り替え、完了済み時間枠の表示有無を選べる
- カレンダー全体を予定名・タスク名・リスト・タグ・元ノートで検索できる。表示密度と詳細表示を切り替えられ、同時刻に重なるGoogle Calendar予定は横方向へ自動分割する
- 習慣の予定日・達成状態と日別フォーカス時間を、カレンダーの日・月・一覧表示へ統合できる。表示設定から個別に非表示にできる
- 繰り返しタスクの次回以降を表示期間内へ先読み展開できる。Markdownへ未確定のタスクを複製せず、破線と繰り返しアイコンで読み取り専用の予定として区別する
- カレンダーは日・3日・週・4週・月・年・日別一覧表示に対応。4週表示は月境界をまたぐ連続計画、月表示は6週グリッド、年表示は12か月の予定密度ヒートマップ、一覧表示は今後30日の走査に使える。日付クリックで日表示へ移動し、年表示以外ではタスクのドラッグで日付を変更できる。今日には現在時刻線を表示し、再描画後も日ごとのスクロール位置を保持する
- 日・3日・週の時間軸には、ローカル時刻に加えてIANAタイムゾーンを最大4件表示できる
- Linear: Personal API Keyで自分の未完了担当Issueを読み取り表示
- Jira Cloud: URL・メール・APIトークンで自分の未解決Issueを読み取り表示
- 受信箱にはLinear/Jira/Slackの未処理候補を最大5件表示し、その場でタスク化・時間割へ送る・無視を選べる。「時間割へ」は作成タスクを選択済みにして期限日の日表示を開く。候補の処理中は同じ行の操作をロックし、失敗理由を行内へ表示して再試行できる。同一外部IDの並行取り込みは一本化し、設定保存だけ失敗した場合も既存の外部タグ付きタスクを再利用して重複を防ぐ。取込済み設定に対応するMarkdownタスクがなければ候補へ戻し、明示的な再取込で復元する。対象キーを取得できなければ時間割へ遷移せず、以前の選択による別タスクの誤配置を防ぐ。620px以下では操作を折り返し、44px以上のタップ領域を確保する。Issue全件画面も同じ処理中・エラー・再試行挙動を持ち、自動ラベルで絞り込める
- Linear/Jira/Slackの秘密情報はObsidian SecretStorageへ端末ローカル保存する。旧`data.json`の平文トークンは初回起動時と次回設定保存時に自動移行し、通常設定・移行・バックアップ・復元の永続化データから平文キーを除去する。SecretStorageが利用できない端末では平文へ戻さず設定保存を止めるため、同期先の端末では秘密情報を再選択する
